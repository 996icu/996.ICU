996 とは？
---

「996」勤務体制とは、近年広まりつつある非公式の勤務体制（午前 9 時から午後 9 時まで、週 6 日）のことです。「996」勤務体制を推奨する企業で働くことは、通常、週に少なくとも 60 時間働くことを意味します。
詳しくは Wikipedia の [996 working hour system](https://en.wikipedia.org/wiki/996_working_hour_system) をご覧ください。

原則と目的
---

* 996.ICU は IT 業界の従事者によって始められた取り組みです。他の分野や他の国の方々の議論への参加も歓迎します。

* これは政治運動ではありません。私たちは労働法を断固として支持し、雇用主に対して従業員の正当な権利と利益を尊重するよう求めます。

* クローズドソースからオープンソースへの移行は大きな進歩でした。そして、オープンソースから労働者の権利を同時に重視することへの移行も、また大きな進歩となるでしょう。私たちが目指しているのは、労働者の権利を擁護するオープンソースソフトウェアライセンスを作ることです。

* 私たちは、前向きで建設的な提案にはすべて耳を傾け、成熟した責任ある発言を推奨します。

コミュニティの力
---

 - [955.WLB](https://github.com/formulahendry/955.WLB) は、ワークライフバランスの取れた「955」企業のホワイトリストを管理するリポジトリです。
 - [996.LIST](https://github.com/fengT-T/996_list) は、996 企業と 955 企業のランキングリストのリポジトリです。
 - [996.YAOCL](https://github.com/boycott996/yaocl) Yet Another Overtime Corps List（もう一つの残業企業リスト）。現在のもう一つの匿名投票リストです。
 - [996.Leave](https://github.com/623637646/996.Leave) は、海外での就労を奨励・紹介しています。
 - [996.RIP](https://web.archive.org/web/20190422174052/https://996.rip/) 古いニュースは決して消えない。
 - [996.Petition](https://github.com/xokctah/996.petition) は、関係する政府部門に公開書簡を送ることで請願を行っています。
 - [996.avengers](https://github.com/996-icu-avengers/Natasha) は、求人サイトに `996ICU` と `955WLB` のタグを追加します。
 - [996.OD](https://github.com/zhouF96/996.OD) 職業病は ICU の前兆です。
 - [996.Q](https://github.com/alexddhuang/996.Q) 996 に関する皮肉、ジョーク、ギャグを集めるリポジトリです。
 - [996.survey](https://github.com/0594mazhiyuan/996.survey) 996 の現状に関する調査です。
 - [support.996.ICU](https://github.com/msworkers/support.996.ICU) Microsoft と GitHub の従業員が 996.ICU を支援しています。
 - [996.Blockchain](https://github.com/996BC/996.Blockchain) 996 の証拠のためのブロックチェーンです。
 - [996.Error](https://github.com/MagicLu550/996Error) さまざまな言語で書かれた「996」例外を集めたもので、プロジェクトでそのまま使用できます。

Issues はどこへ？
---

インタラクション制限を有効にしても、Issues 欄は完全に制御不能な状態になっていました。
そのため、GitHub や他の誰かではなく、**私個人**の判断で Issues を無効にしました。
